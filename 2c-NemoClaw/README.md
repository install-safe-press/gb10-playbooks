有關 AI Agent 應用 順序是這樣的 依據順序基礎入門,項目  00-0d 1a~1g之後進行  2a	AI Agent 應用	2a-OpenClaw , 2d	AI Agent 應用	2d-Hermes , 2b	AI Agent 應用	2b-OpenShell , <br>
接著 0z	基礎入門	0z-Reimage 系統Reimage重置之後 進行2c	AI Agent 應用	2c-NemoClaw  <br>
為什麼要系統Reimage重置之後 進行2c	AI Agent 應用	2c-NemoClaw  , 其實在系統重置之後有先行環境要建置,   在 NemoClaw 佈署前應先進行  3g	模型推理	3g-Nemotron-3-Nano	llama.cpp	本地大模型部署 計劃是使用Nemotron-3-Super-120B 目的是為了全 NVIDIA 解決方案的試驗<br>
不做重置也可以沿用之前所做的ollama 使用 Qwen 模型 (playbooks overview最底部有寫到) 或其它模型 <br>
